# AHC055 - Weakpoint

AtCoder Heuristic Contest 055 の解法実装

## 問題概要
N個の宝箱を最小の攻撃回数で全て開ける問題。各宝箱には武器が入っており、武器を使って効率的に他の宝箱を開けることができる。

- N = 200 (固定)
- 各宝箱の硬さ H_i ∈ [100, 500]
- 各武器の耐久値 C_i ∈ [1, 6]
- 武器iで宝箱jへの攻撃力 A_{i,j} ∈ [1, 500]

## 実装アルゴリズム

### 最終版（sol3_final.cpp）

**2段階ハイブリッド法 + 焼きなまし**

#### Phase 1: 賢い貪欲法で初期解構築
1. 各宝箱の「武器価値/素手コスト」を評価
2. 最も費用対効果の高い宝箱から順に開ける
3. 各段階で利用可能な武器を効率的に使用

#### Phase 2: 焼きなまし法で改善
- **解の表現**: 宝箱を開ける順序のpermutation
- **近傍操作**:
  - 2点スワップ（70%）
  - 区間反転（20%）
  - 初期部分の重点探索（10%）
- **温度スケジュール**: 指数冷却
- **実行時間**: 1.85秒

## 改善案

1. **初期解の多様化**: 複数の初期解から最良を選択
2. **近傍操作の拡張**: より大きな変更を加える操作の追加
3. **ビームサーチの併用**: 初期k個の宝箱選択を最適化
4. **武器割り当ての最適化**: 順序固定で割り当てのみを最適化
5. **温度スケジュールの調整**: 適応的な温度管理
