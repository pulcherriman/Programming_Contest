# AHC055 改善分析レポート

## 現状の問題点

### 武器使用率が極端に低い
- **総攻撃回数**: 39,040回
- **武器での攻撃**: 685回（1.75%）
- **素手での攻撃**: 38,355回（98.25%）

### 原因分析
1. **攻撃力分布の偏り**
   - A_{i,j} = round(500.0 / rand_double(1.0, 500.0))
   - この生成方法により、小さい値（1-10）が非常に多い
   - 攻撃力1-3の武器が大半を占める
   - 素手（攻撃力1）とほぼ同等

2. **高攻撃力武器の稀少性**
   - 攻撃力が高い武器（50以上）は稀
   - これらの武器を効率的に活用することが鍵

### データ例（test_input.txtの3行目）
```
4 1 4 1 3 2 46 6 1 2 4 3 49 1 3 1 114 1 2 2 ...
```
- 大部分が1-10の低攻撃力
- 46, 49, 114などの高攻撃力武器が散在

## 改善戦略

### 1. 高攻撃力武器の優先的な獲得と使用

**現在の問題**:
- 初期の宝箱選択が「武器価値/素手コスト」のみで判断
- 高攻撃力武器を持つ宝箱を見逃している可能性

**改善案**:
```cpp
// 武器の最大攻撃力を考慮
double evaluateWeaponQuality(int w) {
    double max_power = 0;
    double avg_power = 0;
    for (int j = 0; j < N; j++) {
        max_power = max(max_power, (double)A[w][j]);
        avg_power += A[w][j];
    }
    avg_power /= N;
    
    // 最大攻撃力と平均攻撃力の両方を考慮
    return max_power * 0.7 + avg_power * 0.3;
}
```

### 2. 武器の使用戦略の最適化

**現在の戦略**:
- 単純に攻撃力順にソート
- 過剰攻撃（オーバーキル）を考慮していない

**改善案**:
```cpp
// 残りHPに応じた武器選択
if (remaining <= 50) {
    // 低HP: 無駄を最小化（ちょうど良い攻撃力を選ぶ）
    sort by: min(waste = max(0, power - remaining))
} else if (remaining <= 200) {
    // 中HP: 効率重視（攻撃力-1の大きい順）
    sort by: (power - 1) desc
} else {
    // 高HP: 高攻撃力武器を積極的に使う
    sort by: power desc
}
```

### 3. 動的計画法による最適割り当て

各宝箱を開ける際に、利用可能な武器の最適な組み合わせをDPで計算:

```cpp
// dp[h] = 硬さhを削るのに必要な最小攻撃回数
// 制約: Hは最大500、武器数は最大200、耐久値は最大6
// 計算量: O(H * Σ耐久値) = O(500 * 1200) = O(600K) → 十分高速
```

### 4. 初期宝箱選択の改善

**現在**: 武器価値/素手コストで貪欲に選択
