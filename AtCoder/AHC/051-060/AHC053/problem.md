# AHC053 問題要約

## 問題概要
N枚の空白カードと、L以上U以下の整数をM個ランダム生成する乱数生成器を使ったゲーム。

## ゲームの流れ

### 1. カードへの数値記入
- 1以上U以下の整数A₁, A₂, ..., Aₙを自由に選ぶ
- i番目のカードにAᵢを書き込む

### 2. 乱数生成
- 乱数生成器によりM個の整数B₁, B₂, ..., Bₘが生成される

### 3. カードの分配
- 任意の枚数のカードを捨てる（0枚以上）
- 残ったカードをM個の山に分ける（空の山も可）

## 目標
j番目の山のカードに書かれた数の合計をBⱼに近づける

## 得点計算
- j番目の山のカードの総和をSⱼとする
- 誤差: E = Σⱼ₌₁ᴹ |Sⱼ - Bⱼ|
- 得点: round((20 - log₁₀(1 + E)) × 5 × 10⁷)

## 入出力形式

### 入力
1. N M L U（カード枚数、山数、乱数下限、乱数上限）
2. A₁ A₂ ... Aₙを出力後、B₁ B₂ ... Bₘが入力される

### 出力
1. A₁ A₂ ... Aₙ（各カードに書く数）
2. X₁ X₂ ... Xₙ（各カードの所属：0=捨てる、1~M=山番号）

※各出力後は改行と標準出力のflushが必要

## 制約・入力生成方法
- N = 500
- M = 50
- L = 10¹⁵ - 2×10¹²
- U = 10¹⁵ + 2×10¹²

### 入力生成方法
- L以上U以下の整数を独立かつ一様ランダムにM個生成
- それらを昇順に並べたものがB₁, B₂, ..., Bₘとなる
- つまり、B₁ ≤ B₂ ≤ ... ≤ Bₘ が保証される
