# AHC048 解法検討

## 問題の整理

### 基本設定
- パレット: 20×20のグリッド（N=20固定）
- チューブ絵の具: K種類（4≤K≤20）
- 目標色: H=1000色を順番に作成
- 操作回数上限: T回（4000≤T≤64000）
- チューブ使用コスト: D（10≤D≤10000）

### 色の表現・混合
- 色: (C, M, Y) の3次元ベクトル（0≤C,M,Y≤1）
- 混合: 重み付き平均 `(v₁×p₁ + v₂×p₂) / (v₁ + v₂)`
- ウェル: 連結成分、k個のマスで最大kグラムまで格納可能

### 操作
1. チューブから1グラム追加（コストD）
2. 1グラム取り出して画伯に渡す（H回必須）
3. 1グラム廃棄
4. 仕切りの出し入れ（ウェルの合併・分割）

### スコア
- 絶対スコア = `1 + D×(V-H) + round(10⁴×E)`
- 誤差E = Σ[(目標色 - 実際の色)²]の各成分の和
- V: チューブ使用回数

## 解法のアプローチ

### 1. 基本戦略

#### A. 贪欲的最近傍戦略
各目標色に対して、現在持っているチューブの組み合わせで最も近い色を作る方法を探す。

**長所:**
- 実装が比較的簡単
- 各色に対して局所的に最適化

**短所:**
- 次の色への準備ができない
- チューブの無駄遣いが多い可能性

#### B. バッチ処理戦略
似た色をグループ化し、まとめて効率的に作成する。

**長所:**
- チューブの利用効率が良い
- 中間色を再利用可能

**短所:**
- 順序制約で複雑になる
- グループ分けが難しい

#### C. 動的プログラミング戦略
各ステップで最適な選択を行うよう、将来のコストも考慮する。

### 2. アルゴリズム的要素

#### A. 色空間での最適化
- **問題**: 目標色に最も近い混合を見つける
- **手法**: 線形代数（最小二乗法）
- **詳細**: K種類のチューブから重み w₁, w₂, ..., wₖ で混合して目標色に近づける
  ```
  minimize ||Σwᵢ × colorᵢ - target||²
  subject to Σwᵢ = 1, wᵢ ≥ 0
  ```

#### B. パレット管理の最適化
- **問題**: ウェルの配置と容量の効率的な利用
- **手法**: グラフ理論、Union-Find
- **詳細**: 
  - ウェルの合併・分割の最適なタイミング
  - 容量制約下での色の保存戦略

#### C. 近似解法
- **問題**: 厳密解は計算量的に困難
- **手法**: 
  - 貪欲法 + 局所改善
  - 山登り法
  - 焼きなまし法（時間があれば）

### 3. 具体的な実装戦略

#### Phase 1: 基本実装（貪欲法）
1. **単純な1色ずつ生成**
   - 各目標色について、最適な混合比を計算
   - 必要なチューブを順番に投入
   - 1グラム取り出し

2. **最適混合比の計算**
   ```cpp
   // 目標色targetに対して、チューブ色tubes[]の最適な重みweights[]を計算
   vector<double> findOptimalWeights(Color target, vector<Color> tubes) {
       // 制約付き最小二乗問題を解く
       // simplex法 or 制約付き勾配降下法
   }
   ```

#### Phase 2: 効率化
1. **色の類似度によるクラスタリング**
   ```cpp
   double colorDistance(Color a, Color b) {
       return sqrt((a.c-b.c)² + (a.m-b.m)² + (a.y-b.y)²);
   }
   ```

2. **中間色の再利用**
   - 複数の目標色に有用な中間色を事前に作成
   - ウェルに保存して後で利用

3. **パレット管理**
   - 大きなウェルを作って大量生産
   - 小さなウェルで微調整

#### Phase 3: 高度な最適化
1. **動的計画法的アプローチ**
   - 状態: (現在のウェル状態, 残り目標色)
   - 遷移: 各操作
   - 評価: 予想総コスト

2. **ビームサーチ**
   - 有望な状態を複数保持
   - 各ステップで候補を展開

### 4. 実装上の考慮点

#### A. 数値計算の精度
- doubleの誤差を考慮した判定（1-1e-6）
- 色の成分は0-1の範囲内

#### B. メモリ・時間制約
- 制限時間3秒
- メモリ1024MiB

#### C. 出力形式
- 初期仕切り配置
- 操作列（最大T回）

### 5. 初期実装プラン

1. **データ構造定義**
   ```cpp
   struct Color { double c, m, y; };
   struct Well { Color color; double volume; set<pair<int,int>> cells; };
   class Palette { /* ウェル管理 */ };
   ```

2. **基本操作の実装**
   - チューブ追加
   - 色取り出し
   - 仕切り操作
   - ウェル合併・分割

3. **最適化問題の解法**
   - 制約付き最小二乗
   - 貪欲選択

4. **メイン処理**
   - 各色について最適戦略を選択
   - 操作列を生成

### 6. 評価・改善方針

1. **段階的改善**
   - まず動くバージョンを作成
   - 局所改善を追加
   - 高度なアルゴリズムへ発展

2. **パフォーマンス測定**
   - 誤差E の最小化
   - チューブ使用量V の最小化
   - バランスの調整

3. **ケース分析**
   - Dが大きい場合: チューブ使用量重視
   - Dが小さい場合: 精度重視
   - K、Tによる戦略変更

この解法では、まず貪欲法による基本実装から始めて、段階的に最適化していく方針とします。色空間での最適化とパレット管理が鍵となる問題です。

## 解法実装記録

### solution_claude_1.cpp - 基本実装
- シンプルな単色選択戦略
- 各目標色に最も近いチューブ色を選択
- 最小限の操作でコストを抑制
- **結果**: スコア 2,309,646（最優秀）

### solution_claude_2.cpp - 修正版
- 大型ウェル（50マス）と中型ウェル（25マス）の実装
- 適切な廃棄処理（query "2"後の残り塗料廃棄）
- 基本的な混色最適化機能
- **結果**: スコア 19,722,993

### solution_claude_3.cpp - 高度最適化版
- **中間色分析**: 2色混合で作れる有用な中間色を事前計算
- **クラスタリング**: K-means的な手法で目標色をグループ化
- **高精度最適化**: 1色、2色、3色混合を段階的に試行
- **IntermediateColor構造体**: 再利用可能な中間色の管理
- **AdvancedColorOptimizer**: 複数のチューブの重み付け混合
- **重み制限**: 2色混合は最大8グラム、3色混合は最大4グラム
- **問題点**: 高精度な色を作るが操作コストが高い（14,010操作）
- **結果**: スコア 23,129,183（色精度は最高だが総合スコアは最低）

#### solution_claude_3の特徴
- 中間色再利用のためのインフラは整備済み
- しかし実際には毎回新規作成＋廃棄を繰り返している
- クラスタリング機能は実装されているが活用されていない
- 色精度向上のために複雑な混合を行うが、操作コスト増大でスコア悪化

#### 改善の余地
- 一度作った絵の具の再利用機能の実装
- クラスタリングを活用したバッチ処理
- パレット容量管理の最適化
- 操作コストと色精度のバランス調整

### solution_claude_4.cpp - 絵の具再利用版
- **PaintStock構造体**: 絵の具の在庫管理（残量、位置、使用予定）
- **ColorCluster構造体**: 類似色のクラスタリング管理
- **SmartPalette**: 大ウェル（50マス）、中ウェル（25マス）、小ウェル（1マス）の階層管理
- **絵の具再利用**: 既存の絵の具から使用可能なものを優先選択
- **期限管理**: 使用予定を過ぎた絵の具を自動廃棄（10ターン猶予）
- **クラスタリング**: 類似色とターン距離を考慮してバッチ処理
- **結果**: スコア 2,305,426（2位）

#### solution_claude_4の特徴
- **再利用戦略**: `findBestExistingPaint()` で既存の絵の具から適切なものを検索
- **スマートクラスタリング**: 色の類似度（距離0.01未満）とターン距離（50ターン以内）でグループ化
- **在庫管理**: `PaintStock` で絵の具の位置、残量、使用計画を一元管理
- **期限切れ自動廃棄**: 使用予定を過ぎた絵の具は自動的に廃棄処理
- **階層ウェル**: 必要量に応じて大・中・小のウェルを使い分け

#### アルゴリズムの流れ
1. **入力・初期化**: チューブ色と目標色を読み込み、最適ウェル配置を設定
2. **スマートクラスタリング**: 類似色をグループ化（最大5色、50ターン以内）
3. **クラスタ処理**: 
   - 単独色: 既存絵の具から最適なものを選択、なければ新規作成
   - バッチ色: 平均色を計算して必要量をスケールアップして作成
4. **在庫管理**: 各ターンで期限切れ絵の具を自動廃棄
5. **最適化**: `SimpleColorOptimizer` で1色・2色混合の最適解を計算

### solution_claude_5.cpp - 16ウェル最適化版
- **16ウェル管理**: 4×4グリッドの固定レイアウト（各ウェル5×5区画）
- **Well構造体**: 現在の色、残量、位置を管理
- **Action評価システム**: 各目標色に対して全ウェルの全行動を評価
- **動的意思決定**: ターンごとに最適な行動を選択（既存使用・追加・新規混合）
- **スコア計算**: `D×(操作回数-1) + 10000×色誤差`
- **結果**: スコア 2,302,856（最優秀）

#### solution_claude_5の特徴
- **固定ウェル配置**: 4×4 = 16個の固定ウェル、各5×5区画の中央に配置
- **包括的行動評価**: 各目標色に対して以下を全て評価
  1. 既存の絵の具をそのまま使用（追加コストなし）
  2. 各チューブを1-3グラム追加（D×(グラム数-1)のコスト）
  3. 空ウェルでの2色混合（1-2グラムずつ、最大4グラム）
- **リアルタイム最適化**: 事前計画なし、各ターンで全選択肢を評価
- **シンプル構造**: クラスタリングや在庫管理なし、純粋な行動最適化

#### アルゴリズムの流れ
1. **パレット設定**: 4×4グリッドのウェル配置を出力
2. **各ターゲット処理**: 
   - `findBestAction()`: 16ウェル×複数行動パターンを全評価
   - スコア = `D×(追加操作-1) + 10000×色距離`
   - 最小スコアの行動を選択
3. **行動実行**: 
   - 必要な絵の具追加操作を出力
   - ウェルの状態を更新（色・残量）
   - 1グラム消費操作を出力

#### パフォーマンス比較
- **solution_claude_4**: 絵の具再利用により中規模問題で効率的
- **solution_claude_5**: 各ターンの完全最適化により小規模・高精度問題で最優秀
- **適用場面**: 
  - 高D値: claude_5の単純戦略が有効
  - 低D値: claude_3の高精度戦略が有効
  - 中D値: claude_4の再利用戦略が有効
