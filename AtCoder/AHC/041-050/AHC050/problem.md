# AHC050 問題

## 問題概要

N×Nのマス目からなるスケートリンクがあり、1体のロボットを使ってゲームを行う。

### 座標系
- 左上のマスの座標を (0,0) とする
- 下方向にi マス、右方向にj マス進んだ位置のマスの座標を (i,j) とする
- N×N マスの外部はすべて岩で覆われており、侵入できない

### 初期状態
- M個のマスに岩が置かれている
- あなたの獲得賞金は0円

## ゲームの流れ

### 1. 列Pの宣言
あなたは岩の置かれていない N²-M マスを任意の順番で並べた列
P = (P₀, P₁, …, P_{N²-M-1}) を宣言する。

### 2. ロボットの配置
岩の置かれていないマスの中から一様ランダムに1つが選択され、そこにロボットが配置される。

### 3. ゲームループ
i = 0, 1, …, N²-M-1 の順に以下を繰り返す：

1. **ロボットの移動方向決定**
   - ロボットが上下左右の4方向のうち1つを一様ランダムに選択
   
2. **ロボットの移動**
   - ロボットがその方向に岩にぶつかるまで直線的に進行
   - ロボットが1マスも動かない場合もある
   
3. **岩の設置とゲーム終了判定**
   - マス P_i に岩を置く
   - そのマスにロボットがあった場合：ロボットが潰されてゲームが終了
   - そのマスにロボットがなかった場合：あなたは1円を獲得

## 目標
最終的に獲得できる賞金の期待値ができるだけ大きくなるような列Pを求める。

## 得点計算
最終的に獲得できる賞金の期待値をEとする。このとき、
round((N²-M-1) × 10⁶ × E) の得点が得られる。

## テストケース情報
- 合計で150個のテストケースがある
- 各テストケースの得点の合計が提出の得点となる
- 一つ以上のテストケースで不正な出力や制限時間超過をした場合、提出全体の判定がWAとなる
- コンテスト時間中に得た最高得点で最終順位が決定され、コンテスト終了後のシステムテストは行われない
- 同じ得点を複数の参加者が得た場合、提出時刻に関わらず同じ順位となる

## 入力形式

```
N 
M
S₀,₀ …S₀,N-1
⋮
S_{N-1,0} …S_{N-1,N-1}
```

### 制約
- 全てのテストケースにおいて、N = 40に固定されている
- M は N²/10 以上 N²/4 以下の整数である
- S_{i,0} …S_{i,N-1} は `#.` からなるN文字の文字列
  - S_{i,j} が `#` なら初期状態でマス (i,j) に岩が置かれている
  - S_{i,j} が `.` なら初期状態でマス (i,j) には岩が置かれていない

## 出力形式

求めた列PのうちP_i = (x_i, y_i) としたとき、以下の形式で標準出力に出力する：

```
x₀ y₀
⋮
x_{N²-M-1} y_{N²-M-1}
```

### 制約
- 全てのP_iは相異なる
- 全てのP_iについて、初期状態においてマスP_iに岩が置かれていない

## 入力生成方法

1. まず、N = 40とする
2. 次に、MをN²/10以上N²/4以下の整数から一様ランダムに選出する
3. 最後に、N²個のマスから相異なるM個を一様ランダムに選び、選ばれたマスに岩を置くことでマス目の初期状態を定める

## 重要なポイント

- N = 40固定
- M の範囲：160 ≤ M ≤ 400
- 岩が置かれていないマス数：N² - M = 1600 - M 個
- 列Pの長さ：N² - M - 1 個（最後の1つはロボットが残る可能性があるため除外）
- ロボットの移動は完全にランダム
- 目標は期待値の最大化
